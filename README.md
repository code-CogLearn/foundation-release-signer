# foundation-release-signer

Independent AIEDU foundation release signing authority for
`code-CogLearn/coglearn-platform`.

This repository currently stops at `TRUST_ROOT_COMMIT`. It contains the
branch-protection policy, CODEOWNERS, dispatch-only authority workflow,
independent source revalidation, and the downstream candidate bundle contract.
It contains no private key, public key, allowed-signers entry, trusted signer
material, secret value, signed release, or host-delivery mechanism.

See [the bootstrap boundary](docs/BOOTSTRAP.md) and
[the candidate bundle contract](contracts/CANDIDATE_BUNDLE.md).
